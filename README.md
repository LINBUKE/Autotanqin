# 风物之诗琴自动化工具

把歌曲伴奏（MP3/WAV）自动转成**浏览器模拟器**可用的按键谱，并提供可视化微调、四点校准与模拟点击播放。

支持两件乐器：
- **风物之诗琴**：3 排 21 键（C4~B6），和弦/伴奏可分层
- **首席女高音**：2 排 14 键（C4~B5），单声部人声；支持「人声匹配」把一个音节配一个音；
  映射时自动做「人声稳化」——修 basic_pitch 转写常见的八度混乱/碎片/毛刺，
  ①页勾选过「先人声分离再转写」时还会按分离出的人声轨实测基频校准（只换八度、不改音级）

> ⚠️ 安全边界：本工具**仅针对浏览器版风物之诗琴模拟器**，不注入、不读内存、不修改游戏文件，不连接《原神》游戏本体。把同类脚本用于游戏本体风险自负。

## 流程

```
音频 MP3/WAV → ①（可选人声分离）音频转 MIDI → ② MIDI 映射到当前乐器
            → ② 人声匹配（自动识别音节 / 手动歌词）→ ③ 浏览器编辑器微调
            → ④ 四点定位校准 → ⑤ 模拟点击播放 → ⑥ 端到端测试
```

## 安装

### 自动（推荐，给没有 Python 的电脑用）

直接双击 **`启动.bat`**，环境引导会自动完成全部准备，无需手动装任何东西：

1. 检测本机真实 Python（自动排除微软商店的 python 占位符），要求 3.9 ≤ 版本 < 3.12
2. 没有兼容 Python 时，自动从国内镜像下载并静默安装 Python 3.10.11（用户级，不需要管理员）
3. 自动创建 `.venv` 并通过清华/阿里云/中科大/华为云镜像依次安装依赖（断网或 SSL 劫持会自动换源重试）
4. 关键库做真实导入冒烟，损坏会自动补装

引导相关文件：`启动.bat` → `launcher.ps1`（检测/Python/venv）→ `install_python.ps1`（装 Python）→ `bootstrap.py`（装依赖）。菜单模式：`启动.bat menu`。

### 手动

```bash
cd piano_tool_project
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

> basic-pitch 0.4.x 使用 onnxruntime 推理，无需 TensorFlow。`requirements.txt` 锁了 `setuptools<81`
> （resampy 需要 `pkg_resources`，81+ 已移除）。
>
> 人声分离为**按需安装**：demucs 不在 `requirements.txt` 里。首次在①页勾选「先人声分离再转写」时
> 会弹窗确认，再从镜像下载 demucs + CPU 版 PyTorch（约 500MB~1GB）；装失败也不影响普通转写。

## 用法

### 桌面版（推荐）

双击 `启动.bat`，或：

```bash
python desktop_app.py
```

全部流程（转写、可选人声分离、乐器选择、人声匹配、映射、编辑器、四点校准、模拟播放）
在一个 Tkinter 窗口内完成。窗口下方「日志」区会实时显示下载、分离、转写、播放的进度。

- ②页顶部「乐器」下拉切换 风物之诗琴 / 首席女高音，音域、键位、分层说明会整体跟着变
- ②页「分层 / 声部整理方式」里选 **「钢琴曲适配（旋律/低音/和声，钢琴谱推荐）」**：
  会先识别调性、整体移到自然音阶，再按旋律 / 低音 / 和声三个角色分排与减薄：
  **旋律只留最高 1 个到中/高排、低音到底排、和声到中排**，转写造成的孤立
  八度尖峰会折回；同一簇最多 3 个键，长音不再占复音位（原琴是拨弦）。
  **钢琴谱优先用这个**，不要再用老的「按音高分层」。
  - 「同时最多几个音」默认 **4**（老版本）；原琴谱最常用 **3**
    （旋律 1 + 低音 1 + 和声 1）；选中「钢琴曲适配」会自动按 3 生成。
  - **键盘弹奏**（勾选③页「原神键位优化」）保留同时和弦；
    **鼠标弹奏**会自动把和弦拆成 30ms 短促琶音（单个鼠标按不了真和弦）。
- 「独立分轨」需要 MIDI 里真的有**多条音轨**；只有一条音轨时（例如音频转写
  出来的 MIDI），会自动改成「整体落位」（保留原曲音程，不再按音高硬切三层），
  日志里会提示。不管单轨还是多轨，都会按原琴谱习惯把**旋律整体抬到中/高排、
  底排留给低音**（只换八度、不改音级），旋律更亮、不再又低又闷。
- ②页「🎤 人声匹配（一字一音）」：
  - **自动识别**：选歌曲音频（优先用①页分离出的 `vocals.wav`），自动检测音节，一个音节一个音
  - **手动输入歌词**：粘贴歌词按字对齐；数量不一致时先弹窗确认，可选声调参与
- 想要最快复查：音频直接选 `data/output/separated/.../vocals.wav`，并取消勾选「先人声分离」

### 界面与预设（不用再每次重调）

- **界面字号**：顶部「界面字号」下拉（85%~200%）或 `A−`/`A＋`，改完立刻生效并自动记住；
  窗口大小/位置/最大化也会记住，下次打开还是你上次的样子。
- **用户预设**：顶部「预设」区三个按钮
  - `导出设置…` → `用户预设.ini`：②③④⑤ 全部设置（**不含**歌曲 MIDI 和每键采样，几十 KB，方便分享）
  - `导出全量(含MIDI/采样)…` → 额外把当前 MIDI 与 ④ 录下的**每键琴声**一起内嵌进去
    （约 2 MB），换机器 / 换新版本导入即还原，**不用再对着游戏重录一遍**
  - `导入…` → 选 `.ini` 一键恢复全部设置（含采样，导入后编辑器「模拟音」直接可用）
- **关掉重开自动沿用**：关闭软件时会把当前设置存进 `data/last_session.ini`，下次启动自动应用。
  也就是说：调好一次就够，不用截图记参数。

### 双屏用户（重要）
③ 四点校准页顶部有**「演奏显示器」**下拉：**请选中模拟器/游戏所在的那块屏**，然后再截屏校准。
选定后只截这块屏，点击坐标也按这块屏计算，副屏放左、放右、放上、放下都对。

- 这个选择只存本机（`data/ui_prefs.json`），**不写进预设文件**——换机器后它没有意义；
- 换屏/换布局后要**重新截屏校准**（旧坐标是按上一块屏算的），程序会自动清掉旧截图；
- 用**「原神键位优化」（键盘弹奏）**的话完全不受双屏影响——它发的是字母键，与屏幕坐标无关。

### ④ 逐键音色采集：采「系统声音」而不是麦克风

设备下拉里两种前缀，**采模拟器的声音选 🎵**：

- **🎵 系统声音(回环)** —— 直接抓这块扬声器正在播放的声音，不用麦克风、不录环境噪音。
  录屏软件里的「系统声音」就是它。要选**模拟器实际出声的那块**（笔记本扬声器 / HDMI 显示器 / 耳机）。
- **🎤 麦克风 / 立体声混音** —— 物理输入设备，会录进房间噪音。

设备已经按声卡去重（Windows 会把同一声卡列四遍），而且**只列真正能录的**，所以清单只有个位数。

**采样前先花 30 秒跑一次「音频自检」**（发布包根目录的 `音频自检.bat`，双击即可）：
它会逐块听一遍所有回环设备并打印峰值，直接告诉你**哪一块此刻在出声**。

```
[13] 峰值 0.00000  🎵 LECOON2721U-2 (NVIDIA High Definition Audio)
[14] 峰值 0.01814  🎵 扬声器 (EDIFIER W820NB)   ← 这块正在出声（④ 页选它）
```

这是最容易被忽略的一环：**多声卡/蓝牙/HDMI 场景下系统里有好几块输出，选错一块就会
"开流成功、不报错、完整录下 1 秒钟静音"** —— 表现和"程序没做对"一模一样。录屏软件之所以
总能录到，是因为它跟着系统默认设备走；本程序为了只测模拟器那块必须指定设备，
所以选错就成了"怎么也采不到"。

**不知道选哪块？** 点旁边的 **「🎯 找正在出声的」**：让模拟器持续弹几秒，
程序会逐个设备听电平，自动选中正在出声的那块（并显示各自电平）。
如果所有回环都很安静，它会接着测麦克风/立体声混音，把有声音的推给你。

采样前还有一道**静音预检**：当前设备 0.5 秒内没声音就直接中止并提示，
不会再让你干等 21 个键（约一分钟）才看到「全部未检测到」。

整轮 21 个键**只用一条录音流**（约 26~32 秒），不会出现「每个键都报
-9999 Unanticipated host error」那种情况。

**采样是按固定节拍走的**：每 1.25 秒按一个键，每个键之后录满 0.95 秒再判——
不是在按键瞬间去"抓"那一声，而是**录下来事后分析**。这样上一键的余音、背景音乐、
蓝牙音箱的底噪都只算"背景"，只要这一段里有明显上升就算这个键发声了，
比实时判定稳得多（实时判定调高就漏、调低就乱）。

**录完的琴声会存下来，不用每次再录**：每个键的 wav 在 `data/key_samples/`
（约 1.6 MB），编辑器「模拟音」就是放这些文件。想换机器 / 换了新的发布包也能带走——
点 ④ 页下面的 **「把采样存进预设…」**（等同顶部「导出全量」），采样就以 base64 写进
同一个 `.ini`；到新环境 `导入…` 一次，21 个键的声音全回来，导入后可以直接在编辑器里
点「模拟音」听。体积上限 25 MB（正常 21 键远小于它），超过会提示「这次没打包」。

**用「原神键位优化」（键盘弹奏）时注意**：
- 点「采集每键音色」后会**倒计时 3 秒**，请在这 3 秒内把模拟器/游戏切到前台——
  键盘按键只对前台窗口生效，切晚了开头几个键会被吞；
- 每个键会**按住 80 毫秒**再松开（0 毫秒的游戏会当成没按，那几个键就采不到）；
- 采样期间**别切窗口**。个别键没采到不会中断，会继续采完，
  结束时列出是哪几个——这几个键没有音色样本，编辑器「模拟音」会用默认音；不影响播放。
- **采样时测到的延迟只作参考，不参与播放**：逐键提前量会改变音与音的相对时间，
  同一份谱子会错拍/不和谐；播放统一使用⑤页的「提前量(ms)」。
- 采样期间**别切窗口**，程序按 1.25 秒一拍往下走；
- 个别键没采到会自动重按一次；开头连续 5 个都没声音会中止并提示（多半是设备/窗口不对）；
- 采完会记录延迟读数（**仅参考**，播放不再逐键补偿）；真正给编辑器「模拟音」用的是
  `data/key_samples/*.wav`，某个键没采到音色时编辑器会用默认音。

回环功能依赖 `pyaudiowpatch`（PyAudio 的 WASAPI loopback）。**不用装 VB-Cable、不用开
「立体声混音」**，蓝牙耳机 / HDMI 显示器 / 主板声卡都能直接采。
`启动.bat` 会自动装；手动装：`.venv\Scripts\python.exe -m pip install pyaudiowpatch`。
没装时程序会明确提示装法，这时可以退回 🎤「立体声混音」。

**如果换了设备还是全静音**，说明声音确实没进这块扬声器。依次确认：
① 模拟器/浏览器没被静音（Windows 音量合成器）；② 任务栏音量的输出设备就是 🎵 那一块；
③ 系统音量不为 0；④ 「测试音频(2秒)」时的电平。

### 边弹边改：播放 + 同时编辑

⑤ 页「▶ 开始播放」右边有 **「▶ 播放 + 同时编辑」**：点一下会同时做两件事——
打开浏览器里的编辑器、并开始播放。

- 编辑器工具栏 **「🗑 清空」后面有个状态灯**：
  - **● PASS（绿）** = 已连上桌面版软件（鼠标悬停能看到「正在播放 / 待机」和当前琴谱音数）；
  - **● FAIL（红）** = 没连上（直接双击 html 文件打开、或软件已退出时就是这样）。
- **播放头会跟着软件走**：软件开始播放后，编辑器里的竖线自动跟着走，跑出屏幕会自动滚动；
  **暂停/停止时停在当前位置**（快速三按右键暂停也一样），之后你可以直接在那一处改音符。
  跟随期间编辑器的 ▶ 会置灰（避免两个播放头打架），暂停后即可恢复试听。
- **模拟音**：编辑器工具栏 PASS/FAIL 后面有个「🔈 模拟音」按钮。点一下会去取桌面软件里④「逐键音色采集」时录下的真实琴声，用它代替网页默认的电子音——试听就是真的琴声了。
  按钮显示 `🔊 模拟音 ✓ 21` 表示已载入 21 个键；显示 `🔇 没有音色` 说明还没做过④采样。
  - 点开后**进入「本页试听」**：播放 / 开头 / 停止三个键变绿，状态灯变成 **🔊 SIM**，
    并**自动断开与桌面软件的同步**（不再显示 PASS/FAIL、不再跟随软件进度）；
    再点一次就恢复跟随。读采样要先联网，所以是「先加载、再断联」。
  - 这个模式下三个键是**可点**的：播放中再点「播放」就是停止（不会点了没反应）。
  - 每个音会**自然响完**（约 0.85 秒的真实琴声，不是被剪断的一小截）；
    同一个键连着弹会收掉前一下，不会叠成一团。
  - 点开后**进入「本页试听」**：播放 / 开头 / 停止三个键变绿，状态灯变成 **🔊 SIM**，
    并**自动断开与桌面软件的同步**（不再显示 PASS/FAIL、不再跟随软件进度）；
    再点一次就恢复跟随。读采样要先联网，所以是「先加载、再断联」。
  - 每个音会**自然响完**（约 0.85 秒的真实琴声，不是被剪断的一小截）；
    同一个键连着弹会收掉前一下，不会叠成一团。
  某个键没录到就自动回退电子音，不会静音。
- **播放中快速三按鼠标右键 = 暂停，再按三下 = 从暂停处继续**（不用回去点按钮，也不用按 F7）。
  三次要在 0.7 秒内按完才算；按住不放不会连续触发。暂停时界面显示「已暂停在 12.3s」，
  编辑器播放头也停在那一刻；想彻底结束就点「■ 停止」。
  暂停/停止都是立刻生效的（就算正处于前奏的长休止里也一样）。

### 网页控制台

本地起一个 Flask 服务，所有操作在浏览器里点完，无需命令行：

```bash
pip install flask          # 已加入 requirements.txt
python app.py              # 自动打开 http://127.0.0.1:8000
```

控制台包含四个步骤卡片：
1. **音频 → MIDI**：上传 MP3/WAV 转写（需 basic-pitch）。
2. **MIDI → 琴谱**：映射为 events.json，并可一键在「音符编辑器」中微调。
3. **四点校准**：上传模拟器截图，在网页上点 左上→右上→右下→左下 四角，自动算 21 键坐标（比 OpenCV 弹窗更方便）。
4. **模拟播放**：按琴谱+坐标模拟点击；支持 dry-run 试跑与真实播放，急停把鼠标移到屏幕左上角。

> 「按音符时值按住」：**键盘模式**会真正同时按住多个键；**鼠标模式**同一时刻只能按住一个键，长音会被下一个音松开。风物之诗琴是拨弦音色，按住不会像合成器那样持续发声，长音主要靠自然余音；想真正按住长音/和弦请用键盘模式。

顶部「打开音符编辑器」按钮即原 `editor/editor.html`，并支持 `?events=` 自动载入琴谱。

> 网页控制台目前只覆盖 21 键风物之诗琴的基础流程；乐器切换、人声匹配、人声分离只在桌面版提供。

### 一键菜单

```bash
python run.py              # 选 1 启动网页控制台
```

### CLI（typer）

```bash
python -m piano_tool convert  data/input/song.mp3 -o data/output/song.mid
python -m piano_tool map      data/output/song.mid -o data/output/events.json
python -m piano_tool calibrate
python -m piano_tool play     data/output/events.json --speed 1.0
python -m piano_tool test-simulator --midi data/output/song.mid
```

可视化编辑器：浏览器打开 `editor/editor.html`，导入 `events.json`，拖动微调后导出。

## 编辑器操作

| 操作 | 效果 |
|---|---|
| 拖动音符上下 | 改音高，实时试听 |
| 拖动音符左右 | 改时间（吸附 10ms 网格，缩放自适应） |
| **点击左侧键名列** | **选中这一行全部音符**，之后拖动任一个 = 整行一起动（Shift 加选） |
| 空白处拖动 | 框选多个（Shift+点击加选 / Esc 取消） |
| 双击空白 | 添加音符 |
| **「✚ 新建标准音符」**（工具栏第二行） | 进入放音符模式：鼠标带着一个半透明音符，**点哪儿生成哪儿**，可连续点；Esc 退出 |
| **「✂ 音符分割」**（工具栏第二行） | 进入切分模式：鼠标移到音符上出现**一条竖线**，点一下就从那儿劈成两半（太靠边不给切） |
| **右键** | 弹出菜单：**在这里切分 / 复制 / 粘贴到此处 / 删除**（点空白处右键只剩「粘贴到此处」） |
| **Ctrl+C / Ctrl+V** | 复制选中音符 / 粘到播放头处（**保留音符之间的相对间隔**，一步可撤销） |
| Delete / Ctrl+Z | 删除选中 / 撤销 |
| **拖到底部「待处理区」** | 暂放 5 行里（**不导出、不保存、不演奏**），拖回上方即恢复；**摆放保留原来的时间间隔**，不会按拖进去的顺序重排 |
| **顶部「乐器」下拉** | 风物之诗琴（21 键）/ 首席女高音（14 键），轨道与字母整体切换 |
| 导入 events.json | **自动识别**谱子属于哪件乐器并切换，字母与轨道一眼对得上 |
| 缩放输入框 | 改时间轴比例（px/秒） |
| 点时间轴 / 空格 | 定位播放头 / 播放试听（从播放头开始） |

## 键位布局

**风物之诗琴**（21 白键，C4(60)~B6(95)）：
`Z X C V B N M / A S D F G H J / Q W E R T Y U`

**首席女高音**（14 键，C4(60)~B5(83)）：
`A S D F G H J`（下排 C4~B4） + `Q W E R T Y U`（上排 C5~B5）

黑键受物理限制会被就近替换为白键，听感必然变化。人声映射只允许 ±12 换八度，不改音级。
