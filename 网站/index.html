立即开始 了解功能

核心功能

从原始音频到模拟器出声，每一步都有对应的工具与可视化界面。

🎧

音频转 MIDI

MP3 / WAV 一键转写为 MIDI。可选先做人声分离或伴奏分离，带人声的歌留主旋律，纯器乐去人声更干净。

🎼

智能映射与分层

「钢琴曲适配」自动识别调性、按旋律 / 低音 / 和声分排减薄，长音不再占复音位，钢琴谱直接可用。

🎤

人声匹配（一字一音）

自动识别音节，把歌词逐字对齐到音符；「人声稳化」修正八度混乱与碎片毛刺，支持人声轨基频校准。

🎛️

可视化编辑器

单文件网页编辑器：拖动改音高时间、框选批量编辑、音符分割、复制粘贴、待处理区，边播边改。

🎯

四点校准

截屏后点四个角，自动算出全部琴键坐标；支持多显示器，选中模拟器所在屏幕即可。

🖱️

模拟点击 / 键位播放

鼠标模拟点击或键盘键位演奏，支持倍速、提前量、同时播放伴奏对比，以及可选的防封随机化。

🎚️

高级六轨分离

人声 / 贝斯 / 鼓 / 吉他 / 钢琴 / 其他 六轨独立分出，可单独试听、导出、勾选合成后转写。

💾

预设与音色采样

全部设置一键导出 / 导入 .ini 预设，含 21 键真实琴声采样，换机器导入即还原，不用重录。

🧩

桌面版 + 网页控制台

Tkinter 桌面版全流程一个窗口完成；也有 Flask 网页控制台与 typer CLI，适合自动化脚本调用。

使用流程

六步从音频走到自动演奏，中途随时可以在编辑器里微调。

音频 MP3/WAV→ ① 转写 / 分离→ ② 映射琴谱→ ③ 编辑器微调→ ④ 四点校准→ ⑤ 模拟播放

音频 → MIDI

选歌转写；带人声勾「先人声分离再转写」，纯器乐直接转更快更准。

MIDI → 琴谱

选乐器（风物之诗琴 / 首席女高音），钢琴谱推荐「钢琴曲适配」分层；需要唱歌再做人声匹配。

可视化微调

打开编辑器拖动音符、分割复制、边播边改，改完导出 events.json。

四点定位校准

截屏后依次点琴面四角，自动算出每个键的坐标；键盘弹奏模式不受屏幕坐标影响。

模拟点击播放

可先 dry-run 试跑，再真实播放；急停把鼠标移到屏幕左上角，也可叠加伴奏对比听感。

端到端测试

一键 test-simulator 验证谱子与坐标，确认无误即可长期使用。

键位布局

两件乐器共用三排字母键位，切换乐器后编辑器与映射会整体跟着变。

风物之诗琴 · 21 键（C4~B6）

QWERTYU
ASDFGHJ
ZXCVBNM

3 排 21 白键，和弦 / 伴奏可分层

首席女高音 · 14 键（C4~B5）

QWERTYU
ASDFGHJ

2 排 14 键，单声部人声，支持人声匹配

黑键受物理限制会被就近替换为白键，听感必然变化。

快速开始

面向 Windows，双击即可用；也支持手动安装与命令行。

双击 启动.bat

环境引导自动完成：检测 Python（3.9 ≤ 版本 < 3.12 且带 tkinter）、必要时自动安装、创建虚拟环境并装好依赖。

进入桌面版

全部流程在一个窗口内完成，下方日志区实时显示下载、分离、转写、播放进度。

（可选）网页控制台 / CLI

运行 python app.py 打开 http://127.0.0.1:8000；或用 python -m piano_tool convert / map / play 走命令行。
